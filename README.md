## What is MCP?

The [Model Context Protocol](https://modelcontextprotocol.io/) is an open standard that lets AI assistants (Claude, Cursor, Antigravity, etc.) securely connect to external tools and data sources. Think of it as "USB-C for AI" — a single standard interface for all your services.
